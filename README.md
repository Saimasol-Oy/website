# Saimasol landing page

A responsive, single-page landing page for Saimasol Oy.

Open index.html in a browser, or serve this directory with a local HTTP server. No build tools are required.

The original supplied logo is in saimasol-logo.png. The page uses a navy, soft blue and near-white palette inspired by the logo. Styling and page content are in index.html.

hello@saimasol.fi is a draft contact address and must be confirmed before receiving inquiries.

Typefaces are loaded from Google Fonts.
